# PRODUCT.md - pinghue

## Register

Brand. The only web surface is the landing page at `docs/` (pinghue.com); its job is design-as-communication, not app UI.

## What it is

`pinghue` is a colored, concurrent ICMP/TCP ping monitor CLI/TUI for maintenance windows. Local tool, no server, no daemon. Distributed via PyPI (`uv tool install pinghue`) and Homebrew (`inxbit/tap`). The site's single job: get an operator to install it in under a minute of reading.

## Target users

Network operators, SREs, and sysadmins running maintenance windows, migrations, and reachability checks, often at 02:00 under change-freeze pressure. Terminal-native audience; they trust tools that state their scope honestly.

## Brand personality

Dense, vigilant, calm at 2am. Honest about what it is not (the README has a "What This Is Not" section; the site keeps it). The name is the thesis: ping + hue, color IS state.

## Brand tokens (committed, do not reinvent)

Decision 2026-10-05: the user explicitly opened the previous site identity (the "Slate + Signal" dark palette, Archivo + JetBrains Mono, the green-amber-red-blue wordmark gradient) and replaced it on the site with the world below. Slate + Signal remains the TUI's palette as documented in the README; the site no longer mirrors it.

- World: ink on warm paper, one monospace grid. "The table is the terrain."
- Palette (`docs/site.css`): paper `#efede6`, ink `#161513`, secondary ink `#4f4d48`, rule `#b3afa4`; state colors green `#1d7a37` (healthy), amber `#9c5a00` (slow/intermittent), red `#b8322b` (loss/down); blue `#1f5fbf` only for the keyboard focus ring.
- Rule: state colors appear only with state (latency) meaning, never as decoration.
- Wordmark: the plain word "pinghue" set in ink in the same monospace face; no gradient.
- Type: one face, Inconsolata (variable, self-hosted subset `docs/fonts/inconsolata-var-ascii.woff2`), width axis at 80% for body text. Mono is earned: the product is literally a terminal.
- Signature element: the table is the terrain. A block-glyph headline, "THE TABLE IS THE TERRAIN.", typed as rows of the full-block glyph and cut into cells by a CSS mask (generated by `scripts/site-headline.mjs`), above a canvas latency terrain (`docs/site.js`) fed by a deterministic simulated run, standing over a real HTML table with pinghue's real columns. On load a landscape clip (`docs/media/ridge.mp4`) is rendered through the glyph ramp and dissolves into the terrain from the horizon forward; a 1s tick advances the run; "head-on" flattens the terrain onto the table's history column and hands over to the real glyphs; "pause" stops everything that moves. A closing band prints a sunrise clip (`docs/media/dawn.mp4`) through the same ramp: the window closes.

## Anti-references

No SaaS gradient-blob heroes, no fake dashboards, no marketing buzzwords, no em dashes, no eyebrow-label-on-every-section scaffolding. The site must read like it was made by the people who made the tool.

## Constraints

- Static site, no build step: plain HTML/CSS/JS in `docs/`, deployed by GitHub Pages workflow.
- `tests/site_pages.test.mjs` is a deploy-gating contract on file structure, key copy, palette, and the no-em-dash rule. Update it deliberately alongside content changes.
- Site changes deploy only via PR to `main` (branch protected).

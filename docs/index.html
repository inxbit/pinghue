Watch the whole window.

pinghue is a colored, concurrent ICMP/TCP ping monitor. One dense terminal view for many hosts at once, and structured JSON evidence when the window closes.

uv tool install pinghue

Every host in one table.

dense view
Many hosts in one readable table: per-host latency, loss, jitter, and a live history bar.
icmp / tcp
Default ICMP, or TCP connect checks with -p. Up to 1024 concurrent probes.
json evidence
--output writes a stable schema_version 1 summary for reports, cron, and CI.
whole-run states
Host states reflect everything that happened in the window, not just the last few probes.
scriptable
--no-tui, --count, --duration, and fail-on-down exit codes for automation.
local & safe
No server, no daemon, no credentials. Runs where you run: macOS and Linux.

TUI when you watch. Lines when you script.

ICMP the default

$ pinghue 1.1.1.1 8.8.8.8 example.com

Concurrent echo probes with the full TUI: history bars, states, and keyboard control.

TCP no privileges needed

$ pinghue -p 443 example.com api.internal

Connect checks against any port, 1 to 65535. Refused connections get their own amber marker.

--no-tui for cron and CI

$ pinghue -p 443 example.com -c 3 --no-tui
2026-05-14T18:32:11.420000+00:00 example.com ok latency=14.08ms

One line per probe, fail-on-down exit codes, and --output for the report.

One fixed scale, every run.

A host that blips once stays intermittent until you reset it. A maintenance-window report should reflect everything that happened, not only the final moments.

Close the window with a report.

$ pinghue -f hosts.txt --duration 180 --output maintenance.json
{
  "schema_version": 1,
  "pinghue_version": "4.0.0",
  "run": { "host": "local", "exit_reason": "duration", … },
  "targets": [
    { "target": "db-primary", "state": "intermittent",
      "stats": { "sent": 180, "received": 178, "loss_pct": 1.1, … } }
  ]
}
  • Versioned contract. JSON uses schema_version: 1. Breaking changes require a new schema version.
  • Whole-run stats. stats covers every probe in the run; samples is the recent tail.
  • Private by default. Output files are written 0600, and existing files are never replaced without --overwrite.

· · · # what pinghue is not

Small on purpose.

  • Not a Prometheus, Smokeping, Zabbix, or NMS replacement.
  • Not a long-running metrics database or alerting system.
  • Not a privileged daemon.
  • Not a packet capture or traceroute tool.
  • Not a service that accepts remote network requests.

A focused local tool for maintenance windows, migrations, and quick reachability checks. Nothing more, on purpose.

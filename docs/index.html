TUI when you watch, lines when you script

One command, three ways to run it. Every mode probes your hosts concurrently, up to 1024 probes at a time with --concurrency, and keeps the same whole-run statistics.

The default. Concurrent echo probes with the full TUI: history bars, states, and keyboard control. Press a to show or hide the resolved addresses.

No privileges needed. Connect checks against any port from 1 to 65535. A refused connection prints its own amber ! in the history, so you can tell a closed port from a timeout at a glance.

For cron and CI. One line per probe, exit code 3 when a --fail-on-any-down or --fail-on-all-down condition triggers, and --output for the report.

One fixed scale, every run

Latency maps to the same eight glyphs on every run. Nothing rescales, so rows stay comparable across hosts and across nights. Green until 100 ms, amber past it.

  1. up to 1 ms
  2. up to 3 ms
  3. up to 10 ms
  4. up to 30 ms
  5. up to 100 ms
  6. up to 300 ms
  7. up to 1000 ms
  8. over 1000 ms
  9. lost, down
  10. TCP refused
14 ms glyph 4 of 8, green

A host that blips once stays intermittent until you reset it with r. The report covers the whole window, not only its final minutes.

Close the window with a report

Add --output and pinghue writes a schema-versioned JSON summary when the run ends. Attach it to the change ticket and go back to bed.

Versioned contract
schema_version: 1. Breaking changes need a new schema version.
Whole-run stats
stats covers every probe in the run; samples is the recent tail, at most 1000 per host.
Private by default
Reports are written 0600, and an existing file is never replaced without --overwrite.
Exit codes
0 completed, 1 runtime error, 2 usage error, 3 a fail-on-down condition triggered.

Small on purpose

A focused local tool for maintenance windows, migrations, and quick reachability checks. Nothing more.

  • Not a Prometheus, Smokeping, Zabbix, or NMS replacement.
  • Not a long-running metrics database or alerting system.
  • Not a privileged daemon.
  • Not a packet capture or traceroute tool.
  • Not a service that accepts remote network requests.
